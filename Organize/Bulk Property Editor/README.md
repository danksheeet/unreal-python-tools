# Руководство по инструменту Bulk Property Editor

Этот инструмент позволяет массово изменять свойства выбранных ассетов в Unreal Engine.

## Как это работает

Скрипт выполняет следующие шаги:

1.  **Получение выделения**: Скрипт смотрит, какие ассеты вы выбрали в Content Browser (`unreal.EditorUtilityLibrary.get_selected_assets()`).
2.  **Фильтрация**: Он проверяет каждый выбранный ассет. Если ассет не соответствует указанному классу (например, не является Текстурой), он пропускается.
3.  **Изменение**: Для подходящих ассетов скрипт пытается изменить указанное свойство (`set_editor_property`).
4.  **Сохранение**: После успешного изменения ассет автоматически сохраняется (`unreal.EditorAssetLibrary.save_loaded_asset()`).
5.  **Логирование**: В Output Log выводится информация о каждом измененном файле и итоговая статистика.

## Настройка скрипта

В начале файла `bulk_property_editor.py` есть секция **USER CONFIGURATION**. Вы должны отредактировать эти переменные перед запуском:

```python
# 1. Target Class: Тип ассета (например, unreal.Texture2D, unreal.StaticMesh, unreal.MaterialInstance)
TARGET_CLASS = unreal.Texture2D

# 2. Property Name: Точное имя свойства (наведите курсор на свойство в редакторе, чтобы увидеть его внутреннее имя)
PROPERTY_NAME = "sRGB"

# 3. Property Value: Новое значение. Тип данных должен совпадать (bool, float, int, или Enum)
PROPERTY_VALUE = False
```

## Безопасность

-   **Try/Except**: Изменение свойств обернуто в блок `try-except`. Если один ассет вызовет ошибку (например, свойство защищено от записи), скрипт не упадет, а просто запишет ошибку в лог и перейдет к следующему файлу.
-   **ScopedSlowTask**: Скрипт показывает прогресс-бар, который можно отменить, если процесс затянется.

## Как использовать

1.  Откройте скрипт в любом текстовом редакторе.
2.  Настройте переменные `TARGET_CLASS`, `PROPERTY_NAME` и `PROPERTY_VALUE`.
3.  В Unreal Engine выделите нужные ассеты в Content Browser.
4.  Запустите скрипт через Output Log (переключитесь на Python) или создайте Editor Utility Widget с кнопкой, которая вызывает этот код.
